ITI COPA trade: syllabus, eligibility, jobs & CBT prepITI कोपा (COPA) ट्रेड: सिलेबस, पात्रता, नौकरी और CBT तैयारी

Computer Operator and Programming Assistant (COPA) is the most popular non-engineering ITI trade. It covers computer fundamentals, Windows and Linux, office software, networking, internet safety, web design basics and introductory programming.कंप्यूटर ऑपरेटर एंड प्रोग्रामिंग असिस्टेंट (COPA) सबसे लोकप्रिय नॉन-इंजीनियरिंग ITI ट्रेड है। इसमें कंप्यूटर की मूल बातें, Windows और Linux, ऑफिस सॉफ्टवेयर, नेटवर्किंग, इंटरनेट सुरक्षा, वेब डिज़ाइन की मूल बातें और प्रारंभिक प्रोग्रामिंग शामिल है।

Syllabus outline (1-year trade)सिलेबस रूपरेखा (1 वर्षीय ट्रेड)

  1. Computer components, input/output devices, memory and storage unitsकंप्यूटर के भाग, इनपुट/आउटपुट डिवाइस, मेमोरी और स्टोरेज इकाइयाँ
  2. Operating systems: Windows and Linux commands, file managementऑपरेटिंग सिस्टम: Windows और Linux कमांड, फ़ाइल प्रबंधन
  3. Word processing, spreadsheets (formulas, charts) and presentationsवर्ड प्रोसेसिंग, स्प्रेडशीट (फ़ॉर्मूला, चार्ट) और प्रेज़ेंटेशन
  4. Databases and basic SQLडेटाबेस और बेसिक SQL
  5. Networking: LAN/WAN, IP address, topologies, internet and e-mailनेटवर्किंग: LAN/WAN, IP एड्रेस, टोपोलॉजी, इंटरनेट और ई-मेल
  6. Web design with HTML/CSS, JavaScript basicsHTML/CSS से वेब डिज़ाइन, JavaScript की मूल बातें
  7. Programming basics (VBA/Python as per syllabus), cyber security, e-commerce and accounting software awarenessप्रोग्रामिंग की मूल बातें (सिलेबस अनुसार VBA/Python), साइबर सुरक्षा, ई-कॉमर्स और अकाउंटिंग सॉफ्टवेयर की जानकारी

Outline written in our own words from the public CTS curriculum structure. Always follow the latest official syllabus on Bharat Skills and your ITI's instructions.यह रूपरेखा सार्वजनिक CTS पाठ्यक्रम संरचना के आधार पर हमारे अपने शब्दों में लिखी गई है। हमेशा Bharat Skills पर नवीनतम आधिकारिक सिलेबस और अपने ITI के निर्देशों का पालन करें। bharatskills.gov.in ↗

CBT focus — what gets asked mostCBT फोकस — क्या सबसे ज़्यादा पूछा जाता है

  • Keyboard shortcuts, file extensions and Excel functions (SUM, IF, VLOOKUP) are asked often.कीबोर्ड शॉर्टकट, फ़ाइल एक्सटेंशन और Excel फ़ंक्शन (SUM, IF, VLOOKUP) अक्सर पूछे जाते हैं।
  • Know unit conversions: 1 KB = 1024 bytes, and full forms (RAM, ROM, URL, HTTP).इकाई रूपांतरण याद रखें: 1 KB = 1024 बाइट, और फुल फ़ॉर्म (RAM, ROM, URL, HTTP)।
  • Networking devices (hub, switch, router) and HTML tags are easy marks.नेटवर्किंग डिवाइस (हब, स्विच, राउटर) और HTML टैग आसान अंक हैं।

Jobs, apprenticeship & career scopeनौकरी, अप्रेंटिसशिप और करियर स्कोप

  • Data entry operator, computer operator, office assistantडेटा एंट्री ऑपरेटर, कंप्यूटर ऑपरेटर, ऑफिस असिस्टेंट
  • DTP operator, junior web designer, IT helpdeskDTP ऑपरेटर, जूनियर वेब डिज़ाइनर, IT हेल्पडेस्क
  • Apprenticeship in banks, offices and IT-enabled servicesबैंकों, कार्यालयों और IT-आधारित सेवाओं में अप्रेंटिसशिप
  • Self-employment: cyber café, online services centre (with required registrations)स्वरोज़गार: साइबर कैफ़े, ऑनलाइन सेवा केंद्र (आवश्यक पंजीकरण के साथ)

Q1. 1 kilobyte (KB) is equal to:1 किलोबाइट (KB) बराबर है:
  1. 1000 bits1000 बिट
  2. 1024 bytes1024 बाइट
  3. 1024 bits1024 बिट
  4. 8 bytes8 बाइट

✔ In computing, 1 KB = 2^10 = 1024 bytes.कंप्यूटिंग में 1 KB = 2^10 = 1024 बाइट।

Q2. Which memory loses its data when power is switched off?बिजली बंद होने पर कौन-सी मेमोरी का डेटा मिट जाता है?
  1. ROMROM
  2. RAMRAM
  3. Hard diskहार्ड डिस्क
  4. Pen driveपेन ड्राइव

✔ RAM is volatile memory.RAM वोलेटाइल मेमोरी है।

Q3. The keyboard shortcut to undo the last action in most programs is:अधिकांश प्रोग्राम में पिछली क्रिया को पूर्ववत (Undo) करने का शॉर्टकट है:
  1. Ctrl + YCtrl + Y
  2. Ctrl + ZCtrl + Z
  3. Ctrl + UCtrl + U
  4. Ctrl + XCtrl + X

✔ Ctrl+Z = undo, Ctrl+Y = redo, Ctrl+X = cut.Ctrl+Z = अनडू, Ctrl+Y = रीडू, Ctrl+X = कट।

Q4. Alt + F4 in Windows is used to:Windows में Alt + F4 का उपयोग होता है:
  1. Open task managerटास्क मैनेजर खोलने के लिए
  2. Close the active window/programसक्रिय विंडो/प्रोग्राम बंद करने के लिए
  3. Rename a fileफ़ाइल का नाम बदलने के लिए
  4. Refreshरिफ्रेश के लिए

✔ F2 renames and F5 refreshes.F2 नाम बदलता है और F5 रिफ्रेश करता है।

Q5. The part of the CPU that performs arithmetic and logical operations is the:CPU का वह भाग जो अंकगणितीय और तार्किक क्रियाएँ करता है:
  1. Control unitकंट्रोल यूनिट
  2. ALUALU
  3. Register onlyकेवल रजिस्टर
  4. Cacheकैश

✔ ALU = Arithmetic Logic Unit.ALU = अरिथमेटिक लॉजिक यूनिट।
