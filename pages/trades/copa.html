💻 ITI COPA

COPA is a leading non-engineering trade. CBT emphasises Trade Theory plus Employability Skills — practise IT facts and Office concepts thoroughly.

Engineering/CTS AITT CBT

Syllabus highlights

  • Computer fundamentals: hardware, software, memory, storage
  • Operating systems (Windows basics) and file management
  • MS Word, Excel, PowerPoint — common features & shortcuts
  • Internet, email, browsers and cyber safety basics
  • Networking fundamentals (LAN/WAN, IP awareness)
  • Database & programming awareness as per current CTS modules

CBT focus

Memorise definitions and shortcut-style questions. Don’t skip Employability Skills — 25 Q.

Topic outline (original study map)

  1. Computer fundamentals: hardware vs software, I/O devices
  2. OS basics: files, folders, shortcuts, user accounts
  3. Word processing & spreadsheets — common CBT-style tasks
  4. Networking intro: LAN/WAN, IP idea, browser safety
  5. Internet & email etiquette; phishing awareness
  6. Database & programming intro vocabulary (as per your syllabus year)
  7. Cyber hygiene: passwords, updates, backups

Practice MCQs (exemplar)

Practice / exemplar questions — not from any leaked paper. Written for learning only.

Q1. CPU stands for:
A. Central Processing Unit
B. Computer Personal Utility
C. Control Program Upload
D. Central Print Unit
Answer: A — CPU executes instructions.
Q2. RAM is typically:
A. Permanent storage only
B. Volatile main memory
C. An output device
D. A network cable
Answer: B — RAM loses data when power is off.
Q3. Which is an input device?
A. Monitor
B. Speaker
C. Keyboard
D. Projector
Answer: C — Keyboard sends data into the system.
Q4. http in a web address relates to:
A. A printer protocol only
B. Hypertext Transfer Protocol for web pages
C. Hard disk type
D. Hardware test program
Answer: B — HTTP is the common web transfer protocol.
Q5. A strong password usually has:
A. Only your name
B. Mix of length, letters, numbers, symbols
C. Blank always
D. Dictionary word alone
Answer: B — Length + variety improves strength.
Q6. In a spreadsheet, a cell is identified by:
A. Row and column reference (e.g. A1)
B. Only the file name
C. IP address
D. Printer tray
Answer: A — Cells use column letter + row number.
Q7. Phishing emails often try to:
A. Steal credentials via fake links
B. Cool the CPU
C. Increase RAM
D. Defragment disk automatically
Answer: A — Treat unexpected credential requests as suspicious.
Q8. LAN typically covers:
A. A small local area such as an office/building
B. Only intercontinental links
C. Only satellite TV
D. Printer ink levels
Answer: A — LAN = Local Area Network.
