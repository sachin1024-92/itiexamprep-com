Google Search Console & SEO Setup

How the site owner verifies the domain and submits the sitemap.

Confirm crawlability

Check robots.txt and sitemap.xml.

Verify ownership

Add the site in Google Search Console and complete the shown DNS, file, or meta-tag verification.

Submit the sitemap

Submit sitemap.xml, then use URL Inspection for important pages.

Analytics

Set gaMeasurementId in assets/js/config.js only when a GA4 ID is available.
