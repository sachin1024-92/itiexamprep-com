Google Search Console & SEO Setup

How the site owner verifies the domain and submits the sitemap so Google can discover pages.

Important: Google Analytics tracks visits; it does not by itself improve rankings. Search Console helps you monitor crawl, indexing, and search queries. Both are free Google tools for site owners.

1. Confirm the site is crawlable

  • Open https://itiexamprep.com/robots.txt — it should Allow: / and point to the sitemap.
  • Open https://itiexamprep.com/sitemap.xml — every public page should use absolute https://itiexamprep.com/... URLs.

2. Verify ownership in Google Search Console

  1. Sign in at search.google.com/search-console with the Google account that manages the site.
  2. Add a property for https://itiexamprep.com (URL-prefix) or the domain itiexamprep.com (DNS verification).
  3. Complete verification using the method Google shows (HTML file upload via Hostinger File Manager, DNS TXT record, or HTML meta tag). Prefer DNS or file upload so it stays valid after theme changes.
  4. Wait until Search Console shows “Ownership verified”.

3. Submit the sitemap

  1. In Search Console → Sitemaps, enter sitemap.xml (full URL: https://itiexamprep.com/sitemap.xml).
  2. Submit and check status after a day or two. “Success” means Google fetched the file; indexing of each URL still takes time.
  3. Use URL Inspection on important pages (home, trades, mock tests) and request indexing if needed after major updates.

4. Optional: Google Analytics 4

To measure traffic (separate from Search Console):

  1. Create a GA4 property at analytics.google.com.
  2. Copy the Measurement ID (format G-XXXXXXXXXX).
  3. Open assets/js/config.js on the server and set gaMeasurementId: "G-XXXXXXXXXX". Leave empty to skip loading gtag (no errors).
  4. Redeploy / upload the updated file. Confirm real-time hits after visiting the live site.

5. Language note for this site

English and Hindi share the same URLs. Visitors switch language with the top-left EN | हिन्दी control; preference is stored in localStorage key itie_lang. Pages include hreflang alternate tags pointing to the same URL for en-IN and hi-IN, plus og:locale:alternate for hi_IN.

6. Ongoing hygiene

  • Keep titles and meta descriptions unique per page.
  • After adding pages, update sitemap.xml and re-submit if Search Console does not pick them up.
  • Fix 404s reported in Coverage / Pages reports.
  • Always verify latest exam circulars on DGT / NCVT — this site is unofficial.
