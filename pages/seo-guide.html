Google Search Console & SEO Setup

How the site owner verifies the domain and submits the sitemap so Google can discover pages.

Important: Google Analytics tracks visits; it does not by itself improve rankings. Search Console helps you monitor crawl, indexing, and search queries.

1. Confirm the site is crawlable

  • Open robots.txt — it should Allow: / and point to the sitemap.
  • Open sitemap.xml — every public page should use absolute URLs.

2. Verify ownership in Google Search Console

  1. Sign in at search.google.com/search-console.
  2. Add https://itiexamprep.com and complete DNS, HTML file, or meta-tag verification.
  3. Wait until Search Console shows ownership verified.

3. Submit the sitemap

  1. In Search Console → Sitemaps, enter sitemap.xml.
  2. Submit and check status after a day or two.
  3. Use URL Inspection on important pages and request indexing if needed.

4. Optional: Google Analytics 4

  1. Create a GA4 property and copy the ID in format G-XXXXXXXXXX.
  2. Set gaMeasurementId in assets/js/config.js; leave it empty to skip loading gtag.
  3. Upload the updated file and confirm real-time hits.

5. Language note for this site

English and Hindi share the same URLs. Visitors switch language with the top-left EN | हिन्दी control; preference is stored in localStorage key itie_lang.

6. Ongoing hygiene

  • Keep titles and meta descriptions unique.
  • After adding pages, update sitemap.xml.
  • Fix 404s reported in Search Console.
  • Verify latest exam circulars on DGT / NCVT — this site is unofficial.
