Q1. 1 kilobyte (KB) is equal to:1 किलोबाइट (KB) बराबर है:
  1. 1000 bits1000 बिट
  2. 1024 bytes1024 बाइट
  3. 1024 bits1024 बिट
  4. 8 bytes8 बाइट

✔ In computing, 1 KB = 2^10 = 1024 bytes.कंप्यूटिंग में 1 KB = 2^10 = 1024 बाइट।

Q2. Which memory loses its data when power is switched off?बिजली बंद होने पर कौन-सी मेमोरी का डेटा मिट जाता है?
  1. ROMROM
  2. RAMRAM
  3. Hard diskहार्ड डिस्क
  4. Pen driveपेन ड्राइव

✔ RAM is volatile memory.RAM वोलेटाइल मेमोरी है।

Q3. The keyboard shortcut to undo the last action in most programs is:अधिकांश प्रोग्राम में पिछली क्रिया को पूर्ववत (Undo) करने का शॉर्टकट है:
  1. Ctrl + YCtrl + Y
  2. Ctrl + ZCtrl + Z
  3. Ctrl + UCtrl + U
  4. Ctrl + XCtrl + X

✔ Ctrl+Z = undo, Ctrl+Y = redo, Ctrl+X = cut.Ctrl+Z = अनडू, Ctrl+Y = रीडू, Ctrl+X = कट।

Q4. Alt + F4 in Windows is used to:Windows में Alt + F4 का उपयोग होता है:
  1. Open task managerटास्क मैनेजर खोलने के लिए
  2. Close the active window/programसक्रिय विंडो/प्रोग्राम बंद करने के लिए
  3. Rename a fileफ़ाइल का नाम बदलने के लिए
  4. Refreshरिफ्रेश के लिए

✔ F2 renames and F5 refreshes.F2 नाम बदलता है और F5 रिफ्रेश करता है।

Q5. The part of the CPU that performs arithmetic and logical operations is the:CPU का वह भाग जो अंकगणितीय और तार्किक क्रियाएँ करता है:
  1. Control unitकंट्रोल यूनिट
  2. ALUALU
  3. Register onlyकेवल रजिस्टर
  4. Cacheकैश

✔ ALU = Arithmetic Logic Unit.ALU = अरिथमेटिक लॉजिक यूनिट।

Q6. The binary equivalent of decimal 10 is:दशमलव 10 का बाइनरी रूप है:
  1. 10001000
  2. 10101010
  3. 11001100
  4. 01100110

✔ 8 + 2 = 10 → 1010.8 + 2 = 10 → 1010।

Q7. In a spreadsheet, every formula must begin with:स्प्रेडशीट में हर फ़ॉर्मूला किससे शुरू होना चाहिए?
  1. ##
  2. ==
  3. @@
  4. $$

✔ The equals sign tells the program to calculate.बराबर का चिह्न प्रोग्राम को गणना करने के लिए बताता है।

Q8. The intersection of a row and a column in a spreadsheet is called a:स्प्रेडशीट में पंक्ति और स्तंभ के मिलन बिंदु को कहते हैं:
  1. Cellसेल
  2. Rangeरेंज
  3. Sheetशीट
  4. Fieldफ़ील्ड

✔ Each cell has an address like B3.हर सेल का पता होता है जैसे B3।

Q9. Which function adds values in cells A1 to A5?कौन-सा फ़ंक्शन A1 से A5 तक के मान जोड़ता है?
  1. =ADD(A1:A5)=ADD(A1:A5)
  2. =SUM(A1:A5)=SUM(A1:A5)
  3. =TOTAL(A1,A5)=TOTAL(A1,A5)
  4. =PLUS(A1-A5)=PLUS(A1-A5)

✔ SUM with a range using a colon.कोलन वाली रेंज के साथ SUM।

Q10. VLOOKUP searches for a value in:VLOOKUP किसी मान को कहाँ खोजता है?
  1. The first row of a tableतालिका की पहली पंक्ति में
  2. The first column of a tableतालिका के पहले स्तंभ में
  3. Any random cellकिसी भी सेल में
  4. Chartsचार्ट में

✔ V = vertical; HLOOKUP searches the first row.V = वर्टिकल; HLOOKUP पहली पंक्ति में खोजता है।

Q11. The Linux command to list files in a directory is:डायरेक्टरी की फ़ाइलें दिखाने की Linux कमांड है:
  1. cdcd
  2. lsls
  3. pwdpwd
  4. rmrm

✔ ls lists; cd changes directory; rm removes.ls सूची दिखाता है; cd डायरेक्टरी बदलता है; rm हटाता है।

Q12. The Linux command that shows the current working directory is:वर्तमान डायरेक्टरी दिखाने वाली Linux कमांड है:
  1. pwdpwd
  2. dirdir
  3. whoamiwhoami
  4. mkdirmkdir

✔ pwd = print working directory.pwd = प्रिंट वर्किंग डायरेक्टरी।

Q13. Which HTML tag creates a hyperlink?कौन-सा HTML टैग हाइपरलिंक बनाता है?
  1. <link><link>
  2. <a><a>
  3. <href><href>
  4. <url><url>

✔ <a href="..."> creates a link.<a href="..."> से लिंक बनता है।

Q14. The largest heading in HTML is created by:HTML में सबसे बड़ा हेडिंग किससे बनता है?
  1. <h6><h6>
  2. <h1><h1>
  3. <head><head>
  4. <big><big>

✔ <h1> is the largest, <h6> the smallest.<h1> सबसे बड़ा और <h6> सबसे छोटा है।

Q15. An IPv4 address is made of:IPv4 एड्रेस बना होता है:
  1. 16 bits16 बिट
  2. 32 bits32 बिट
  3. 64 bits64 बिट
  4. 128 bits128 बिट

✔ Four octets of 8 bits each; IPv6 uses 128 bits.8-8 बिट के चार ऑक्टेट; IPv6 में 128 बिट होते हैं।

Q16. Which device connects different networks and forwards data between them?कौन-सा उपकरण अलग-अलग नेटवर्क को जोड़कर उनके बीच डेटा भेजता है?
  1. Hubहब
  2. Repeaterरिपीटर
  3. Routerराउटर
  4. Keyboardकीबोर्ड

✔ Routers use IP addresses to route packets between networks.राउटर IP एड्रेस से नेटवर्कों के बीच पैकेट भेजता है।

Q17. In a star topology, all computers connect to a:स्टार टोपोलॉजी में सभी कंप्यूटर जुड़ते हैं:
  1. Single backbone cableएक बैकबोन केबल से
  2. Central hub or switchकेंद्रीय हब या स्विच से
  3. Ringरिंग से
  4. Printerप्रिंटर से

✔ A central device links every node.एक केंद्रीय उपकरण सभी नोड को जोड़ता है।

Q18. HTTP stands for:HTTP का पूरा नाम है:
  1. High Text Transfer ProtocolHigh Text Transfer Protocol
  2. HyperText Transfer ProtocolHyperText Transfer Protocol
  3. Hyper Transfer Text ProcessHyper Transfer Text Process
  4. Home Tool Transfer ProtocolHome Tool Transfer Protocol

✔ It is the protocol for web pages; HTTPS is the secure version.यह वेब पेज का प्रोटोकॉल है; HTTPS इसका सुरक्षित रूप है।

Q19. URL stands for:URL का पूरा नाम है:
  1. Uniform Resource LocatorUniform Resource Locator
  2. Universal Remote LinkUniversal Remote Link
  3. Unique Resource LineUnique Resource Line
  4. User Resource LocatorUser Resource Locator

✔ A URL is the address of a resource on the web.URL वेब पर किसी संसाधन का पता है।

Q20. A fake e-mail that tricks users into sharing passwords is called:नकली ई-मेल जो उपयोगकर्ता को धोखे से पासवर्ड बताने को कहे, कहलाता है:
  1. Spammingस्पैमिंग
  2. Phishingफ़िशिंग
  3. Bootingबूटिंग
  4. Formattingफ़ॉर्मेटिंग

✔ Never share OTPs or passwords via links or calls.लिंक या कॉल पर कभी OTP या पासवर्ड साझा न करें।

Q21. A firewall is used to:फ़ायरवॉल का उपयोग होता है:
  1. Cool the CPUCPU ठंडा करने के लिए
  2. Block unauthorised network accessअनधिकृत नेटवर्क पहुँच रोकने के लिए
  3. Speed up printingप्रिंटिंग तेज़ करने के लिए
  4. Store filesफ़ाइलें रखने के लिए

✔ It filters traffic according to security rules.यह सुरक्षा नियमों के अनुसार ट्रैफ़िक छानता है।

Q22. The file extension of a modern Excel workbook is:आधुनिक Excel वर्कबुक का फ़ाइल एक्सटेंशन है:
  1. .docx.docx
  2. .xlsx.xlsx
  3. .pptx.pptx
  4. .txt.txt

✔ .docx = Word, .pptx = PowerPoint..docx = Word, .pptx = PowerPoint।

Q23. In a database table, a primary key:डेटाबेस तालिका में प्राइमरी की:
  1. Can repeatदोहराई जा सकती है
  2. Uniquely identifies each recordहर रिकॉर्ड की विशिष्ट पहचान करती है
  3. Is always a nameहमेशा नाम होती है
  4. Stores imagesचित्र रखती है

✔ It must be unique and not empty.यह विशिष्ट होनी चाहिए और खाली नहीं।

  1. GETGET

Q25. In PowerPoint, the shortcut to insert a new slide is:PowerPoint में नई स्लाइड जोड़ने का शॉर्टकट है:
